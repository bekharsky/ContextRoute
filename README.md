# ContextRoute

Небольшая утилита для macOS: правило **«приложение-источник → браузер и профиль»**.

## Как работает

- Если ссылка пришла из приложения с правилом, ContextRoute открывает её в выбранном браузере и профиле.
- Если правила для приложения нет, ссылка идёт в выбранный резервный браузер — тот, который был браузером macOS по умолчанию до назначения ContextRoute.
- Включённые переадресации Zoom, Slack и Telegram отправляют известные домены прямо в соответствующее установленное приложение. Если приложение не установлено, ссылка идёт в резервный браузер.
- Раздел **Default handlers** содержит встроенные переадресации из актуального списка Yojam: Zoom, Telegram, Slack, Discord, Spotify, Apple Music, FaceTime, Карты, Microsoft Teams, Figma, Linear, Notion, WhatsApp, Signal, App Store, TestFlight и Podcasts. Discord-ссылки преобразуются в `discord://`.
- В боковой панели три раздела: **App routes**, **Default handlers** и **Settings**. В Settings собраны резервный браузер, тема и язык интерфейса. Интерфейс по умолчанию английский; доступны русский и системный язык, а также системная, светлая и тёмная темы.
- Для браузеров без поддержки выбора профиля ссылка открывается в их обычном профиле.

Папки профилей автоматически определяются для браузеров из каталога Yojam: Chrome Stable/Beta/Canary, Brave Stable/Beta/Dev, Edge Stable/Beta, Vivaldi, Wavebox, Helium, Comet, Яндекс Браузер, Opera/Opera GX, Chromium, Firefox/Developer Edition/Nightly и Zen. Профили Chromium читаются из `Local State`, Firefox — из `profiles.ini`. Для браузеров без совместимого списка профилей можно выбрать сам браузер; ContextRoute откроет его обычным способом.

## Установка

1. Перемести `ContextRoute.app` в `/Applications` и открой его. Если macOS покажет предупреждение, нажми правой кнопкой на приложение в Finder и выбери «Открыть».
2. При первом запуске открывается **App routes** с кнопкой **Make default browser**. Резервный браузер автоматически определяется по текущему браузеру macOS; если это не удалось, откроется **Settings**, где его можно выбрать вручную.
3. В разделе **App routes** добавь правило, выбери приложение-источник, браузер и профиль. Диалог выбора приложения сразу открывается в `/Applications`; диалог папки профилей начинает с автоматически найденной папки браузера.
4. ContextRoute показывает, нашёл ли список профилей. Если браузер установлен в нестандартное место или использует другой каталог данных, нажми **Profile folder…** и укажи папку с `Local State` (Chromium) или `profiles.ini` (Firefox), а не отдельную папку профиля.
5. Нажми **Make default browser** и подтверди выбор в macOS, если система спросит. Пока ContextRoute не назначен для http и https, кнопка доступна вверху страниц настроек, а пункт **Make default browser…** — в меню приложения.
6. После первого запуска приложение запускается в меню-строке, без открытия настроек. Добавь его в **Системные настройки → Основные → Объекты входа**, только если хочешь, чтобы значок ContextRoute был доступен сразу после входа в систему. Для перехвата ссылок macOS сама запустит назначенный обработчик, если он ещё не запущен.

В меню приложения доступны **Settings…**, **About ContextRoute** и **Quit ContextRoute**. **About ContextRoute** открывает системное окно с версией приложения и автором Sergey Bekharskiy.

Выбор профиля опционален. Если оставить «Без выбора профиля», ссылка откроется в браузере-назначении обычным способом.

## Сборка из исходников

Нужен Xcode 27. Открой `ContextRoute.xcodeproj` или собери приложение командой:

```sh
./Scripts/build-app.sh
```

Xcode-проект таргетирован на macOS 27, поэтому системные элементы интерфейса используют актуальное оформление Liquid Glass. Скрипт собирает Release-приложение, копирует его в `ContextRoute.app` и подписывает локальной ad-hoc подписью. Архив не создаётся.

## Данные и ограничения

- Настройки хранятся в `~/Library/Application Support/ContextRoute/config.json`; диагностический журнал — в `~/Library/Logs/ContextRoute/router.log`.
- Для списка профилей приложение читает `Local State` или `profiles.ini` из папки данных браузера. macOS может отдельно запросить доступ к данным браузера; если отказать, список не загрузится. ContextRoute читает метаданные и не изменяет их. Экран отдельно показывает, найден ли файл и удалось ли его прочитать.
- Источник определяется по приложению, которое macOS передало вместе со ссылкой. Если ссылка была скопирована/передана через посредника, macOS может сообщить ContextRoute приложение-посредник.
- Сборка локальная и не нотарифицирована Apple. Для распространения другим людям понадобится Developer ID и нотарификация.
